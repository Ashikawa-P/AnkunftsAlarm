# AnkunftsAlarm

A simple location-based arrival alarm for Android.

Choose a destination on the map, set an alarm radius and start monitoring. AnkunftsAlarm continues tracking in the background and notifies you when you approach your destination.

### Features

* Select a destination on the map or search by address
* Adjustable radius from 100 to 3000 meters
* GPS, network location or both
* Background location monitoring
* Separate sound and vibration settings
* OpenStreetMap-based map without an API key
* Two consecutive location readings inside the radius are required before the alarm triggers

Requires **Android 13 or newer**.
